# probable-waddle
Conducting Vulnerability Assessment and Penetration Testing on a Simulated Web Application Environment
A FinTech company plans to launch a web application for managing personal finances.
A team of 5 Ethical hackers test a simulated version of the app to identify vulnerabilities that could expose sensitive data. Hidden flags represent critical information, ensuring no real data is at risk during testing.
Monitored tools like Burp Suite, testers uncover issues like exposed debug directories, SQL injection vulnerabilities, and misconfigured login forms.
Reduced the weaknesses highlight significant risks that could allow unauthorized access to sensitive information.
Maintained the document with the findings the the team of 5 members recommend fixes to the development team. These include parameter sanitization, input validation, and improved access controls.
Analyzed after implementing these changes, the app undergoes further testing to ensure its security.
